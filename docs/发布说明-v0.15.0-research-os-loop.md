# 发布说明 v0.15.0 Research OS Loop

日期：2026-06-21

## 定位

v0.15.0 把 v0.13 Evidence Runner、v0.14 Hypothesis Engine 和 v0.15 Paper Trade Agent 合并成主链版本。核心目标不是扩展炫功能，而是让 Research OS 具备一条可审计训练飞轮：

`证据 -> 假设 -> 模拟交易候选 -> 模拟交易账本 -> 收益归因 -> Benchmark -> LoRA-ready`

## 关键更新

- Evidence Runner：新增 EvidenceTask / EvidenceResult / EvidenceRun / DLQ，支持轻量任务队列、质量门、HumanGate、Tushare/fallback 数据源和训练飞轮 Evidence Queue。
- Hypothesis Engine：EvidenceResult 可回流 Hypothesis，形成 evidence direction、Evidence Score、Watchtower candidate、HumanGate 状态迁移推荐和 Post-Mortem 草稿。
- Paper Trade Agent：从 stock-feedback trajectory 或 hypothesis evidence-feedback 生成 `rule_baseline / llm_discretionary` 双轨 paper trade 候选，严格携带 `asOfDate` 和 `evidenceCutoff.noFutureData=true`。
- 训练飞轮 UI：新增 Evidence Queue、Paper Trade Agent 队列、settlement refresh audit、LLM discretionary 复盘预检、样本密度审计和“第一条样本向导”。
- Benchmark / LoRA-ready：新增 paper-trade-agent case、discretionary review case、paperTradeAgent curriculum 和一组 PEFT 边界校验。
- 版本标记：应用、npm package、Tauri、Cargo 均升级为 `0.15.0`。

## 写入边界

- 默认 dry-run。
- `--write` 仅写 `.llm-wiki/**` 内对应 artifact。
- 不写正式 `wiki/**`。
- 不改 `raw/**`。
- 不触发真实交易。
- Paper trade 不能冒充真实收益。
- LoRA-ready 不保存原始事实、价格行、公告正文或交易明细；事实留在 retrieval/tool state/sourceRefs。
- 外部 API token 不写入代码、日志、manifest 或文档。

## 剩余缺口

- 真实项目仍需要写入有效 `stock-feedback-trajectory-v1` 或 `trading-hypothesis-evidence-feedback-v1`，让 Paper Trade Agent 队列从空态进入候选态。
- priced-in、entry_wrong、disconfirmed、fundamental_closure 样本密度还需要继续补。
- profitable paper trade 必须 settle + human review 后才可进入低权重 adapter candidate。
- LLM discretionary review runner 当前仍是只读预览，不调用真实 LLM、不写 paper ledger。

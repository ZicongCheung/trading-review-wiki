## 合并范围

### 1. CLI 工程化拆分

- `scripts/codex-ingest.mjs` 保持唯一 CLI 入口。
- `scripts/codex-ingest-lib.mjs` 保持兼容 facade。
- 内部实现迁入 `scripts/codex-ingest/**`：
  - `core/`
  - `ask/`
  - `brain/`
  - `data-source/`
  - `ingest/`
  - `company-research/`
  - `governance/`
  - `cli/`

### 2. 多智能体 ask

- 新增 `ask --agentic`。
- 默认并发度 3。
- 支持 `--agent-concurrency`、`--agent-timeout-ms`、`--no-agent-artifacts`。
- 默认写 `.llm-wiki/agent-runs/**` 审计产物。
- 单 agent 失败时降级继续，全部 agent 失败时整体失败。

### 3. Market Validator 细分候选池

- 主题问题先识别 segment。
- 命中配置时按细分环节构建候选池。
- 未配置主题时回退普通候选池，并提示 `未配置细分环节`。
- 内置覆盖光纤/光互联链和 PCB 产业链。

### 4. Trading Autoresearch Lite

- 新增 research program。
- 新增 locked score。
- 新增 experiment ledger。
- 新增 review-gated policy proposal。
- 默认只写 `.llm-wiki/research-programs/**`、`.llm-wiki/experiments/**`、`.llm-wiki/policy-proposals/**`。
- 不自动改 prompt、segment 配置、wiki/raw 或真实交易动作。

### 5. 公司深研 V2：plugin-led

- 新增推荐入口：

```sh
npm run codex:ingest -- company-research \
  --stock <code|name> \
  --deep \
  --plugin-led
```

- 主程序负责证据采集、证据包、财务底表、业务拆解、模型模板和写入边界。
- Data Analytics 负责模型、口径、单位、tie-out 和证据覆盖质控。
- Public Equity Investing 作为主分析师直接生成公司主报告。
- Investment Banking 只在交易事项触发或 `--force-investment-banking-review` 时参与。
- `deep-company-report.md` 保留为兼容副本。
- 发布门禁仍由 `publish-readiness.json` 控制，不自动写正式 `wiki/**`。

## 不变边界

- 非 agentic `ask` 行为保持兼容。
- `ask` 默认只读。
- `company-research --deep --plugin-led` 不写正式 `wiki/**` 或 `raw/**`。
- `autoresearch proposal` 只生成建议，不自动应用。
- 不做自动交易。
- 不把未复核 agentic answer 或未审阅 action 升级为 high-confidence 自训练样本。

## 后续 Phase

本版目标是 Phase 5A：

```text
self-question
-> ask --agentic
-> market validation
-> attribution
-> autoresearch score
-> proposed policy change
-> human review
```

后续节奏：

- Phase 5：AI 提出改进建议，不自动应用。
- Phase 6：人工批准后应用低风险配置改动。
- Phase 7：达到多次验证阈值后，部分低风险策略自动应用。
- Phase 8：模拟交易闭环验证。
- Phase 9：受控真实交易建议，不直接自动交易。

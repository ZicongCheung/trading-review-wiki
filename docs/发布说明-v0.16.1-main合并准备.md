## 合并范围

### 1. Research OS Agent 编排

- 新增/完善 `research-os agent status/plan/review/step/verify`。
- Codex 聊天窗口作为 SupervisorAgent。
- CLI 负责固定 action map、HumanGate、artifact、verify 和写入边界。
- 写入路径为 `.llm-wiki/research-os/agent-runs/**`。
- 不开放任意 shell，不接 LangGraph/Temporal/Mem0。

### 2. Evidence Runner 与 Web 补证质量门

- EvidenceTask / EvidenceResult / EvidenceRun / DLQ 已接入 stock-feedback verify。
- Tushare adapter 可用。
- Tavily/Web adapter 可用，但只作为 sourceRef discovery。
- Web 结果按官方源、媒体源、门户源、未知线索分级。
- 字段级命中门防止年报摘要误判为订单、客户、出货、收入全部兑现。

### 3. Hypothesis 回流

- Hypothesis Quality Gate、Evidence Score、evidence direction、Watchtower candidate、HumanGate 推荐、Post-Mortem 草稿已落地。
- 当前真实项目还需要继续跑 evidence-feedback 样本。

### 4. Paper Trade Agent

- 候选生成、as-of 截断、双轨、entry/exit plan、positionSizing、invalidationCondition、Benchmark/LoRA-ready 分流已落地。
- paper trade 仍不能冒充真实收益。
- 当前真实项目还有 `paperTradeAgentWrittenCandidates=0`，后续需 HumanGate 后写入。

### 5. 真实交易 execution-result

- 新增 `research-os-execution-result-v1`。
- 交割单是成交事实主证据。
- 日复盘补动机/归因。
- position-tracking 只做汇总校验。
- Tushare 验证市场路径，不替代券商成交事实。
- confirmed real profitable 样本可进入真实收益训练 curriculum。
